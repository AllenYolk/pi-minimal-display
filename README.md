# Pi Minimal Display

An independently maintained Pi extension for compact tool-call presentation.

Project status: engineering setup and specification review. No release or working extension is available yet.

The intended behavior is a compact, expandable tool summary for each user turn, preserving the existing tools, errors, session data, and model context. Runtime UI patches must be reversible and limited to tested Pi versions.

See [the specification review](docs/spec-review.md) for decisions that must be settled before implementation. GitHub Issues will track the work once the repository target is configured.
