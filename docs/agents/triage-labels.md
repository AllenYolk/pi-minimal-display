# Triage labels

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer evaluates scope and next action |
| needs-info | needs-info | Reporter input is required |
| ready-for-agent | ready-for-agent | Specified and ready for agent implementation |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be implemented |

Use these exact strings for engineering skills. GitHub issue state records completion; these labels record triage readiness.
